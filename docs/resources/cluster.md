# ovirt_cluster (Resource)

The ovirt_cluster resource creates and manages clusters in oVirt.

## Example Usage

```terraform
resource "ovirt_cluster" "test" {
  name                              = "my-cluster"
  datacenter_id                     = var.datacenter_id
  cpu_type                          = "Intel SandyBridge Family"
  cpu_arch                          = "x86_64"
  description                       = "Production Compute Cluster"
  comment                           = "Managed by Terraform"
  ballooning                        = true
  memory_policy_over_commit_percent = 150
}
```

## Schema

### Required

- `cpu_type` (String) CPU type/model for the cluster (e.g. `Intel SandyBridge Family`).
- `datacenter_id` (String) Datacenter to create this cluster in.
- `name` (String) User-provided name for the cluster.

### Optional

- `ballooning` (Boolean) Enable memory ballooning for VMs in this cluster.
- `comment` (String) User-provided comment for the cluster.
- `cpu_arch` (String) CPU architecture for the cluster (e.g. `x86_64`).
- `description` (String) User-provided description for the cluster.
- `memory_policy_over_commit_percent` (Number) Memory overcommit percentage for the cluster (e.g. 100, 150, 200).

### Read-Only

- `id` (String) oVirt ID of this cluster.
