# ovirt_storage_domain (Resource)

The ovirt_storage_domain resource creates and manages storage domains in oVirt.

## Example Usage

```terraform
resource "ovirt_storage_domain" "test" {
  name                          = "my-storage-domain"
  host_id                       = var.host_id
  storage_type                  = "nfs"
  storage_address               = "nfs.example.com"
  storage_path                  = "/data/export"
  storage_format                = "v5"
  description                   = "NFS Production Storage Domain"
  comment                       = "Managed by Terraform"
  wipe_after_delete             = true
  critical_space_action_blocker = 5
  warning_low_space_indicator   = 10
}
```

## Schema

### Required

- `host_id` (String) Host ID used to deploy and connect the storage domain.
- `name` (String) User-provided name for the storage domain.
- `storage_address` (String) Storage server address or hostname.
- `storage_path` (String) Storage path or export on the server.

### Optional

- `backup` (Boolean) Designate storage domain for backup.
- `comment` (String) User-provided comment for the storage domain.
- `critical_space_action_blocker` (Number) Percentage threshold for blocking actions on critical space.
- `description` (String) User-provided description for the storage domain.
- `destroy_on_delete` (Boolean) Force removal of the storage domain even if not accessible. Defaults to `false`.
- `format_on_delete` (Boolean) Format the underlying storage when deleting. Defaults to `false`.
- `storage_format` (String) Storage format version (e.g. `v5`).
- `storage_type` (String) Storage type (defaults to `nfs`).
- `warning_low_space_indicator` (Number) Percentage threshold for low space warning indicator.
- `wipe_after_delete` (Boolean) Wipe after delete by default for disks in this storage domain.

### Read-Only

- `id` (String) oVirt ID of this storage domain.
